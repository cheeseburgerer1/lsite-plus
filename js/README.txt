CookieClickerFiles
==================

Open index.html to play, or upload this folder's contents to a static host.
Keep all files and folders together. No build command is needed.

Spacebar clicks the cookie without interfering with typing or dialogs.
Ads, tracking scripts, and automatic update checks are removed.
Heralds vary between 62 and 81, moving by one every 30 minutes.
The normal Heralds upgrade is required to get its production bonus.

Files
-----
index.html       Page structure
style.css        Main game appearance
fonts.css        Font declarations
game-config.js   Game version and local settings
main.js          Main game code
keyboard.js      Spacebar control
heralds.js       Timed herald count
interface.js     Initial page labels
minigame*.js     Garden, Market, Pantheon, and Grimoire
img/             Images and graphics
snd/             Sounds
loc/             Translations
cf-fonts/        Fonts

Upload the CONTENTS of this folder so index.html is at your site's top level.
For Render, use Static Site, publish directory '.', and no build step.
For Cloudflare Pages Direct Upload, upload the ZIP or this folder.

Progress is saved in the current browser. Use Options > Export save / Import
save to transfer progress. No personal game progress is included here.

This multi-file ZIP contains .js files, which Gmail blocks as attachments.
For emailing, use the previously provided single-HTML package instead.
